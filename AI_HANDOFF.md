# Передача проекта другому ИИ

Начни с `docs/AI_HANDOFF_GROK.md`. Для Blender смотри `docs/BLENDER_BRIDGE.md` и `examples/animation_clip.json`. Для работы с телефона смотри `docs/MOBILE_WORKFLOW.md`.

Быстрый контекст: это локальный редактор 3D-анимаций на React/TypeScript/Three.js/Tauri. Не переписывай архитектуру без причины. Сначала запускай browser preview, затем `npm run build` и `npm run lint`. Изменения делай отдельной веткой и показывай diff.
